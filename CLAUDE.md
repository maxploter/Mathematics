# CLAUDE.md

Instructions for agents working in this repo.

## What this repo is

Course materials: lecture PDFs, seminar slides, assignments, exams — one folder per course,
named `<subject>-<institution>-<lecturer>` (e.g. `algebra-1-nmu-avilov`,
`linear-algebra-mit-gilbert-strang`). Inside a course folder, subfolders follow whatever the
course itself calls its material: `Lectures/`, `Listki/`, `Seminars/`, `Homeworks/`,
`Assignment/`, `Exam/`, `Tests/`, `Labs/`, `Recitations/`, `Slides/`, `Practice/`.

Solutions live beside the material they solve, as a `.md` file in the same subfolder — see
`algebra-1-nmu-avilov/Listki/listok-01-zadacha-01.md` for the pattern.

Russian-language courses keep Russian filenames and Russian notes.

## Don't invent progress that isn't verified

The pre-2026 course folders (probability, linear algebra, stats, geometry, etc.) were gathered
over roughly 2025-06 to 2026-04 with no record of what was actually completed — assignment PDFs
are present but their solved/unsolved state hasn't been checked file-by-file. Don't assume an
assignment is done because the PDF exists. When resuming one, say plainly that completion status
is unverified and the first step is to check, rather than asserting a place in the syllabus.

## Agent memory does not live here

This repo holds Maksim's course material and his own solutions, nothing else. Any agent
memory — study plans, session logs, next-actions, research notes on courses or institutions —
belongs in the KnowledgeNexus workspace this repo is wired into as a submodule, not in this repo.
