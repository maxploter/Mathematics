## Рабочие леммы (доказаны по ходу)

**Единственность обратного.** Если `xy = e` и `xz = e`, то `y = z`.
Доказательство: `xy = xz` ⇒ `x⁻¹(xy) = x⁻¹(xz)` ⇒ (ассоциативность) `(x⁻¹x)y = (x⁻¹x)z` ⇒
`ey = ez` ⇒ `y = z`. ∎

**Закон сокращения.** `xy = xz ⇒ y = z` (и симметрично справа) — то же рассуждение.

## Задача 2а

> Докажите, что если в группе любой элемент имеет порядок 2, то она абелева.

**Решение.** Пусть `g² = e` для всех `g ∈ G`. Возьмём произвольные `a, b ∈ G`.

1. `b·a·a·b = e` — посчитано напрямую: `aa = e`, остаётся `bb = e`. Ни одного предположения,
   только условие и ассоциативность.
2. Домножаем обе части слева на `ba`:
   - слева `(ba)(ba)(ab) = e·(ab) = ab`, так как `(ba)² = e` (условие для элемента `ba`);
   - справа `(ba)·e = ba`.
3. Значит `ab = ba`. ∎

Замечание: `(ba)⁻¹ = ba`, потому что в такой группе каждый элемент сам себе обратный.

## Задача 1

> Заполнив таблицу умножения, классифицируйте все группы порядка 3 и 4.

«Классифицировать» = перечислить все группы данного порядка с точностью до изоморфизма.
Полное решение = полнота (перебор) + существование (пример) + различность (инвариант).

### Порядок 3

Пусть `G = {e, a, b}`.

- `ab ≠ a` (иначе `b = e`), `ab ≠ b` (иначе `a = e`) ⇒ **`ab = e`**, то есть `b = a⁻¹`.
- `a² ≠ a` (иначе `a = e`); `a² ≠ e` — иначе `a` обратен сам себе, но обратный единствен и
  равен `b ≠ a` ⇒ **`a² = b`**.
- Аналогично **`b² = a`**.

Таблица определена однозначно.

Существование: `Z/3Z` (или повороты треугольника на 0°/120°/240°).
Различность: список из одного пункта.

**Вывод: групп порядка 3 ровно одна — `Z/3Z`.**

### Порядок 4 — в работе

`G = {e, a, b, c}`. Возможные порядки неединичного элемента — только 2 или 4
(случай `ord = 3` исключается: при `a³ = e` для четвёртого элемента `c` произведение `c·a`
не помещается никуда — **проверить самостоятельно**).

**Ветка A: все неединичные элементы порядка 2.** Разобрана самостоятельно. Диагональ вся из
`e`; `ab` не может быть `e`, `a` или `b` ⇒ `ab = ba = c`, аналогично `ac = ca = b`,
`bc = cb = a`. Это четверная группа Клейна `V₄ ≅ Z/2Z × Z/2Z`.
Пример: симметрии неквадратного прямоугольника.

**Ветка B: есть элемент порядка 4.** Не доделана. Приём: не заполнять 16 клеток подряд, а идти
по цепочке степеней `a, a², a³, a⁴` — все элементы окажутся степенями `a`.

**Различность веток** (осталось): инвариант — число решений `x² = e`.
