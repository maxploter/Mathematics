# Mathematics

Self-study, run as two parallel tracks so foundations and curiosity don't have to compete for
the same session.

- **`bottom-up/`** — a real course, worked start to finish, in order. Currently: **НМУ
  (Независимый московский университет)**, Математический анализ-1 + Алгебра-1, autumn 2026, as a
  remote вольнослушатель — see `nmu.md`. Slow, sequential, sometimes boring — that's expected,
  not a signal to switch. The earlier MIT 6.041 probability material
  (`probability-mit-john-tsitsiklis/`) is now supplementary, for when Теория вероятностей is
  reached.
- **`top-down/`** — start from a real phenomenon (own health data, a game, a news claim) and
  reach for whatever math explains it. Each unit in `top-down/units/NN-slug/` ends in something
  that runs and something that could be shown to another person. This is the shareable half.

The rest of this repo (`analytic-geometry-course-mipt-kozhevnikov/`,
`linear-algebra-mit-gilbert-strang/`, `mathematical-statistics-*/`, `calculust-1-mipt-ivanov/`,
`transition-to-advanced-mathematics-ut/`, `probability-book-rvershyn/`) is prior material,
gathered over roughly a year (first commit June 2025, stalled April 2026) and not currently
active. Don't start a third track from these without a deliberate decision at a review point —
see `curriculum.md`.

## Running a session

1. Open `NEXT.md`. It has one concrete next action per track. Do the one that matches tonight's
   slot — don't decide, the decision was already made last session.
2. ~45–60 min: bottom-up first (it has more inertia to overcome), then top-down, or split across
   two sessions in the week. Four sessions/week target, not daily.
3. Before stopping: append one line to `log.md`, rewrite the relevant line in `NEXT.md` with the
   exact next action (file to open, thing to do), and — for top-down units — write the short
   `README.md` in that unit's folder.
4. Sharing is per-artifact, not scheduled. A finished top-down unit *might* be worth posting
   somewhere (LinkedIn, X, wherever fits the content) — judgment call each time, not a rule.

See `CLAUDE.md` for agent-specific rules and `curriculum.md` for the current state and the
review trigger.
